# v1 — Initial MVP

The minimum that lets the agent work with GitHub issues, milestones, and Projects. Ships generic TUI rendering (no dedicated renderers). All write operations require explicit per-call permission approval.

## Scope

| Concern | v1 |
|---|---|
| Tools | `github_issue`, `github_milestone`, `github_project` |
| Backing | REST-first via `@octokit/rest@22.0.0`; GraphQL only for Projects `set_field` option mutations |
| Auth | `GITHUB_TOKEN` env var only; clear error if missing |
| Permission default | `ask` for both reads and writes |
| TUI rendering | `GenericTool` fallback (collapsed 3-line output, click to expand) + generic permission prompt |
| Error handling | typed errors (`GitHubError` subtypes); clear messages; no retry |
| CLI subcommands | none |
| HTTP API | none |

## Service shape

```ts
// packages/ranex/src/github/github.ts
import { Effect, Layer, Context } from "effect"
import { LayerNode } from "@ranex/core/effect/layer-node"
import { Octokit } from "@octokit/rest"
import { graphql } from "@octokit/graphql"
import { Config } from "@/config/config"
import { Git } from "@/git"
import { InstanceState } from "@/effect/instance-state"
import { resolveToken } from "./auth"
import { resolveOwnerRepo } from "./repository"
import * as Issues from "./issues"
import * as Milestones from "./milestones"
import * as Projects from "./projects"

export interface Interface {
  readonly resolveOwnerRepo: (input: { owner?: string; repo?: string }) =>
    Effect.Effect<{ owner: string; repo: string }, GitHubError>
  readonly issue: (repo: { owner: string; repo: string }, op: Issues.Operation) =>
    Effect.Effect<Issues.Result, GitHubError>
  readonly milestone: (repo: { owner: string; repo: string }, op: Milestones.Operation) =>
    Effect.Effect<Milestones.Result, GitHubError>
  readonly project: (input: Projects.Input, op: Projects.Operation) =>
    Effect.Effect<Projects.Result, GitHubError>
}

export class Service extends Context.Service<Service, Interface>()("@opencode/GitHub") {}

export const node = LayerNode.make({
  service: Service,
  layer: Layer.effect(
    Service,
    Effect.gen(function* () {
      // Per-instance: each open directory gets its own clients and default repo.
      const clients = yield* InstanceState.make(
        Effect.fn("GitHub.state")(function* () {
          const token = yield* resolveToken()
          const octokit = new Octokit({ auth: token })
          const graphqlWithAuth = graphql.defaults({ headers: { authorization: `token ${token}` } })
          return { octokit, graphqlWithAuth }
        }),
      )
      return Service.of({
        resolveOwnerRepo: (input) => resolveOwnerRepo(input),
        issue: (repo, op) => Effect.gen(function* () {
          const { octokit } = yield* InstanceState.get(clients)
          return yield* Issues.handle(octokit, repo, op)
        }),
        milestone: (repo, op) => Effect.gen(function* () {
          const { octokit } = yield* InstanceState.get(clients)
          return yield* Milestones.handle(octokit, repo, op)
        }),
        project: (input, op) => Effect.gen(function* () {
          const { octokit, graphqlWithAuth } = yield* InstanceState.get(clients)
          return yield* Projects.handle({ octokit, graphqlWithAuth }, input, op)
        }),
      })
    }),
  ),
  deps: [Config.node, Git.node],
})

export * as GitHub from "./github"
```

## Tool shape

`packages/ranex/src/tool/todo.ts` is the minimal template. The `github_issue` tool:

```ts
// packages/ranex/src/tool/github/issue.ts
import { Effect, Schema } from "effect"
import * as Tool from "../tool"
import DESCRIPTION from "./issue.txt"
import { GitHub } from "@/github/github"

const IssueOp = Schema.Union(
  Schema.Struct({
    action: Schema.Literal("list"),
    state: Schema.Literal("open", "closed", "all").pipe(
      Schema.withDecodingDefault(Effect.succeed("open" as const)),
    ),
    labels: Schema.optional(Schema.Array(Schema.String)),
  }),
  Schema.Struct({
    action: Schema.Literal("get"),
    number: Schema.Number,
  }),
  Schema.Struct({
    action: Schema.Literal("create"),
    title: Schema.String,
    body: Schema.optional(Schema.String),
    milestone: Schema.optional(Schema.Number),
    labels: Schema.optional(Schema.Array(Schema.String)),
    assignees: Schema.optional(Schema.Array(Schema.String)),
  }),
  Schema.Struct({
    action: Schema.Literal("update"),
    number: Schema.Number,
    title: Schema.optional(Schema.String),
    body: Schema.optional(Schema.String),
    state: Schema.optional(Schema.Literal("open", "closed")),
  }),
  Schema.Struct({
    action: Schema.Literal("close"),
    number: Schema.Number,
  }),
  Schema.Struct({
    action: Schema.Literal("comment"),
    number: Schema.Number,
    body: Schema.String,
  }),
)

export const Parameters = Schema.Struct({
  owner: Schema.optional(Schema.String).annotate({
    description: "Repository owner. Defaults to the current git origin remote.",
  }),
  repo: Schema.optional(Schema.String).annotate({
    description: "Repository name. Defaults to the current git origin remote.",
  }),
  operation: IssueOp.annotate({ description: "The issue operation to perform." }),
})

type Metadata = {
  owner: string
  repo: string
  action: string
  count?: number
  url?: string
  number?: number
}

const WRITES = new Set(["create", "update", "close", "comment"])

export const GitHubIssueTool = Tool.define<typeof Parameters, Metadata, GitHub.Service>(
  "github_issue",
  Effect.gen(function* () {
    const github = yield* GitHub.Service
    return {
      description: DESCRIPTION,
      parameters: Parameters,
      execute: (params, ctx) =>
        Effect.gen(function* () {
          const { owner, repo } = yield* github.resolveOwnerRepo({
            owner: params.owner,
            repo: params.repo,
          })

          const mode = WRITES.has(params.operation.action) ? "write" : "read"
          yield* ctx.ask({
            permission: "github",
            patterns: [`issues:${mode}:${owner}/${repo}`],
            always: [`issues:${mode}:${owner}/${repo}`],
            metadata: { action: params.operation.action, owner, repo },
          })

          const result = yield* github.issue({ owner, repo }, params.operation)
          return {
            title: titleFor(params.operation.action, result, owner, repo),
            output: JSON.stringify(result.items ?? result.item ?? result, null, 2),
            metadata: {
              owner,
              repo,
              action: params.operation.action,
              count: "items" in result ? result.items.length : undefined,
              url: "item" in result ? result.item.url : undefined,
              number: "item" in result ? result.item.number : undefined,
            },
          }
        }),
    } satisfies Tool.DefWithoutID<typeof Parameters, Metadata>
  }),
)

function titleFor(action: string, result: unknown, owner: string, repo: string): string {
  if (action === "list") {
    const count = (result as { items?: unknown[] }).items?.length ?? 0
    return `${count} issues in ${owner}/${repo}`
  }
  if (action === "create") {
    const item = (result as { item?: { number?: number } }).item
    return item ? `created #${item.number}` : `created issue`
  }
  return `issue ${action}`
}
```

`github_milestone` and `github_project` follow the same shape with their own operation unions and permission patterns (`milestones:<mode>:<owner>/<repo>` and `projects:<mode>:<owner>` respectively).

## Permission model

Patterns are glob-matched via `Wildcard.match` (`packages/core/src/util/wildcard.ts`). Grammar:

- `issues:read:<owner>/<repo>`
- `issues:write:<owner>/<repo>`
- `milestones:read:<owner>/<repo>`
- `milestones:write:<owner>/<repo>`
- `projects:read:<owner>`
- `projects:write:<owner>`

`Permission.evaluate` (`packages/ranex/src/permission/index.ts:28-38`) returns `"ask"` when no rule matches. Durable allows come from `opencode.json`:

```json
{
  "permission": {
    "github": {
      "issues:read:acme/*": "allow"
    }
  }
}
```

"Allow always" in the TUI is session-scoped only (in-memory, cleared on restart).

## Auth

`GITHUB_TOKEN` env var only for v1. Read in `packages/ranex/src/github/auth.ts`. If missing, raise `AuthMissing` with a message telling the user to set `GITHUB_TOKEN`. Do not reuse the GitHub Action runner's OIDC `exchangeForAppToken` (`packages/ranex/src/cli/cmd/github.handler.ts:988`) — it is Actions-specific and depends on the opencode.ai service.

Never accept a token as a tool argument, never include it in `metadata`, never log it.

## Repo resolution

Every operation accepts explicit `owner`/`repo`. If omitted, `resolveOwnerRepo` runs `git remote get-url origin` via `Git.Service` and parses with `parseGitHubRemote` (`@/util/repository`). Partial override (owner without repo) is rejected. `github_project` always requires explicit `{ owner, number }` for the project target.

## TUI rendering (v1: no changes)

Out of the box:

- **Permission prompt**: uses the fallback renderer at `packages/tui/src/routes/session/permission.tsx:372-380` → `" Call tool github"`. Works, generic. Dedicated renderer ships in M7.1.
- **Tool execution**: `toolDisplay(part.tool)` (`index.tsx:639-641`) falls through to `GenericTool` (`index.tsx:1786-1818`) → collapsed 3-line preview of `output`, click to expand.

## Out of scope for v1

- Dedicated TUI renderers (M7).
- Rate-limit retry / backoff (M8.1).
- CLI subcommands (M9).
- HTTP API routes.
- OAuth device flow / `gh auth token` fallback.
- Releases, PRs, Actions, teams, secrets, repository administration.
